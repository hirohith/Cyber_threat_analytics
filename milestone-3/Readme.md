# Milestone 3 — Threat & Incident Analytics

Milestone 3 focuses on analyzing cybersecurity incident data to identify threat patterns, incident characteristics, response performance, and business impact through interactive Power BI visualizations.

## Objectives

- Analyze cybersecurity incidents across different dimensions
- Identify major attack types and threat patterns
- Analyze incident severity and threat severity
- Examine geographic distribution of incidents
- Evaluate incident response performance
- Analyze financial losses and affected users
- Develop interactive dashboards for security analysis and decision support

## Analytics Covered

### Incident Analysis
- Total incident volume
- Incident distribution by attack type
- Incident severity analysis
- Threat severity analysis
- Incident trends over time

### Geographic Analysis
- Incident distribution across states
- City-level incident analysis
- Identification of areas with higher incident concentrations

### Response Performance
- Average response time
- Response-time analysis across incident categories
- Comparison of response performance across locations and risk/severity dimensions

### Business Impact
- Financial loss analysis
- Data compromised analysis
- Affected user analysis
- Outcome and mitigation analysis

## Dashboard

The Milestone 3 dashboard provides interactive visualizations for exploring cybersecurity incidents and identifying important patterns in:

- Threat activity
- Attack types
- Severity
- Geographic distribution
- Response performance
- Financial impact
